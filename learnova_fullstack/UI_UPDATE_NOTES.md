# Learnova UI Update

This version updates the Flutter frontend to match the provided clean Learnova mobile UI style:

- White/soft gradient background
- Purple Learnova branding
- Large bold headings
- Rounded glass input fields
- Soft cards with subtle shadows
- Purple gradient primary buttons
- iOS-style bottom navigation
- Updated Splash, Login, Sign Up, Dashboard, Courses, Tasks, Study Planner, Progress, Profile, Notifications, Settings, Feedback and Help screens

Backend functionality remains connected through the existing FastAPI APIs.
